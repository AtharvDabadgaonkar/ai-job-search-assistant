# AI-Powered Job Search Assistant (B2C)

An interactive product case study, shipped as a single self-contained HTML file (no build step, no dependencies). Open it directly, embed it in a portfolio, or host it on GitHub Pages.

## About

A working slice of an AI job-search product: a clickable assistant, a live application funnel, and the A/B test behind a **+28% click-through** lift.

- Owned full lifecycle: roadmap → PRDs → user stories → MVP
- Tools: Figma, Jira, SQL, A/B testing
- Demo shows the product *and* the PM reasoning that shipped it

## Run locally

Just open `index.html` in a browser. That's it.
